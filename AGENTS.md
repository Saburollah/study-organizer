# Agent instructions

## Agent skills

### Issue tracker

Work for this repository is tracked in GitHub Issues. See `Docs/agents/issue-tracker.md`.

### Triage labels

Use the canonical triage labels `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, and `wontfix`. See `Docs/agents/triage-labels.md`.

### Domain docs

This repository uses a single-context domain model with `CONTEXT.md` at the repository root and ADRs under `Docs/adr/`. See `Docs/agents/domain.md`.
