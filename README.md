# Study Organizer – Projektvision

## Problem

Studierende verwalten ihre Module, Aufgaben und Prüfungen häufig in
unterschiedlichen Anwendungen oder persönlichen Notizen. Dadurch können
Fristen und wichtige Aufgaben leicht übersehen werden.

## Ziel

Study Organizer ist eine Web- und iOS-Anwendung, mit der Studierende ihr
Semester organisieren und ihren Lernfortschritt verfolgen können.

## Zielgruppe

Die Anwendung richtet sich an Studierende an Hochschulen und Universitäten.

## Plattformen

- Webanwendung
- iOS-Anwendung

## Technologie-Stack

- Backend: ASP.NET Core Web API mit C#
- Web-Frontend: Vue 3 mit TypeScript
- iOS-App: SwiftUI mit Xcode
- Datenbank: PostgreSQL
- Datenbankzugriff: Entity Framework Core
- Versionsverwaltung: Git und GitHub

## Ziele der ersten Version

Die erste Version soll folgende Funktionen anbieten:

- Benutzer registrieren und anmelden
- Module erstellen, bearbeiten und löschen
- Aufgaben einem Modul zuordnen
- Aufgaben mit einer Frist versehen
- Aufgaben als erledigt markieren
- Offene und erledigte Aufgaben anzeigen

## Nicht Bestandteil der ersten Version

Folgende Funktionen können in späteren Versionen entwickelt werden:

- Push-Benachrichtigungen
- Lernstatistiken
- Notizen und Datei-Uploads
- Stundenplan
- Zusammenarbeit mit anderen Studierenden
